Hey! I'm Hyun. I got into coding back in 2023 through [The Odin Project](https://www.theodinproject.com/), where I spent months learning HTML, CSS, and JavaScript and building projects from scratch. I learned a lot, had fun with it, and made this profile along the way.

These days, I'm more of a **hobbyist**. I haven't seriously practiced writing code on my own since those early projects, so I'm rusty with syntax and the little implementation details. What stuck with me is how to think through problems, break them into pieces, and figure out how everything fits together.

I use **AI as a coding partner** now. I bring the idea, work out what I want it to do, and help guide the structure, testing, troubleshooting, and revisions. AI does a lot of the actual implementation. I'm still learning as I go—just a little differently than I did in 2023.

* 🌳 **Then:** Learning web development, JavaScript, and how to build things step by step.
* 🛠️ **Now:** Tinkering with hobby projects, automations, and tools I actually want to use—with AI assistance.
* 🐾 **Around here:** Always happy to meet people, share ideas, and learn something new.
* ☕ **Interests:** Cats, coffee, anime/manga, gacha and other games, Discord, Reddit, and a good lo-fi playlist.
